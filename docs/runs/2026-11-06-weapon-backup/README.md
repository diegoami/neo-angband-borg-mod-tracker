## Behavior and boundaries

- Normal notice produces the selected carried weapon handle and score; power
  includes it (C none sentinel-1). No armour, tactical, enchant or drop tactic.
- HOME candidates are carried, not wielded, and compared with the SAME notice
  config/known-curse/Tarrasque/spell snapshot. Equal or worse never wins.
- Public awareness, known flags/resists/slays and ordinary depth50/90/option,
  digger value/curse/spell/current-tool, usefulness1000 and penalties are retained.
  Quivered throwing weapons are not pack backups. No hidden engine read.
- Named per-instance curse power has no public producer. Default excludes that
  unknown case, rather than inventing removability. Optional public knowledge
  inputs are explicit; tests exercise them without claiming production wiring.
  Unknown Tarrasque death retains C's initial not-known-dead state.
- API2 shop-buy is also HOME retrieval. There is no atomic replace intent;
  this leaf requires a real empty slot even with an existing backup. FORK marks
  that conservative host-capacity limit. This is NOT a native C defect claim.
